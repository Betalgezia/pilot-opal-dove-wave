# Relay

Relay собирает живой пул VPN-серверов из подписок, проверяет их через mihomo и экспортирует самые быстрые узлы для Hiddify и Clash Verge.

## Запуск на Windows в два клика

1. Установите Node.js и зависимости проекта:

```powershell
npm install
```

2. Дважды кликните `relay-start.bat`.

Откроется Vite dev-сервер на `http://localhost:8080`, а Relay автоматически откроет панель в браузере.

Чтобы запустить сервер без автоматического открытия браузера:

```powershell
$env:RELAY_NO_OPEN="1"
npx vite dev --host 0.0.0.0 --port 8080
```

Для внешних запросов из Hiddify используйте LAN IPv4 компьютера, который Relay показывает в разделе «Экспорт». В Windows Firewall должен быть разрешён входящий TCP 8080 для частной сети.

## GeoIP

Страна живого узла определяется по IP-адресу: Relay сначала разрешает hostname, затем использует офлайн-базу `geoip-country`. Результаты дополнительно кэшируются в памяти и в `.relay-cache/geoip.json`. Данные GeoLite2 предоставляются MaxMind; перед распространением и обновлением базы соблюдайте условия её лицензии и EULA.

## Остановка скана

Большая круглая кнопка запускает сканирование и во время работы превращается в кнопку «Остановить». Отмена прерывает сетевые запросы и процесс mihomo, но не удаляет последний успешный результат из кэша.
