# Relay

Relay собирает живой пул VPN-серверов из подписок, проверяет их через mihomo и экспортирует самые быстрые узлы для Hiddify и Clash Verge.

Пока Relay запущен, живая подписка отвечает. Если закрыть панель или выключить ПК, Hiddify больше не получит свежий список.

## Запуск на Windows

1. Установите [Node.js LTS](https://nodejs.org) (20 или новее).
2. Дважды кликните `relay-start.bat`. Он сам проверит Node, поставит зависимости и откроет `http://localhost:8080`.

Если порт 8080 занят, bat откроет уже работающую панель. Чтобы не открывать браузер:

```powershell
$env:RELAY_NO_OPEN="1"
npx vite dev --host 0.0.0.0 --port 8080
```

### Hiddify на этом ПК

Во вкладке «Экспорт» скопируйте URL с `localhost`.

### Hiddify на телефоне

ПК и телефон в одной Wi‑Fi сети. В «Экспорт» выберите LAN IP (кнопка с адресом). В брандмауэре Windows разрешите входящий TCP 8080 для частной сети. `localhost` с телефона не работает.

## Ядро mihomo и Defender

На Windows бинарник ставится в `%LOCALAPPDATA%\Relay\` (`mihomo.exe`). На Linux/macOS — в `.relay-cache/mihomo/` рядом с проектом.

Если защита Windows удаляет или блокирует `mihomo.exe`, добавьте папку `%LOCALAPPDATA%\Relay` в исключения Windows Defender.

Папку можно переопределить переменной `RELAY_MIHOMO_DIR`.

## Режимы скана

По умолчанию **Полный** — один процесс mihomo проверяет весь пул сразу, как раньше.

- **Пакеты** — пачки по 64, процесс перезапускается между пачками, остановка примерно на 80 живых.
- **Группы** — один процесс, в конфиге группы `batch-NNN` по 64, последовательный `/group/{name}/delay` без перезапуска.

Режим учитывается в ключе кэша скана и вшивается в URL подписки (`sm=full|batches|groups`).

Тумблер **«Не блокировать подписку»** (`idle=1`): `/api/sub` отдаёт последний готовый пул и сам скан не запускает. По умолчанию выключен.

## GeoIP

Страна живого узла определяется по IP: Relay резолвит hostname, затем смотрит офлайн-базу `geoip-country`. Кэш — в памяти и в `.relay-cache/geoip.json`. Тумблер GeoIP в панели выключает этот шаг.

This product includes GeoLite2 data created by MaxMind, available from [https://www.maxmind.com](https://www.maxmind.com). Перед распространением и обновлением базы соблюдайте лицензию и EULA MaxMind.

## Остановка скана

Большая круглая кнопка запускает сканирование и во время работы становится «Остановить». Отмена прерывает загрузку списков, DNS/GeoIP и процесс mihomo. Последний успешный пул в кэше остаётся.
